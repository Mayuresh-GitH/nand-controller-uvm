# NAND Controller UVM Testbench

ONFI-compliant NAND Flash Controller verification using UVM 1.2 and Synopsys VCS.

## Structure
- `src/`: UVM components (transaction, sequencer, driver, monitors, agents, env, test)
- `sim/`: compile and run scripts
- `docs/`: ONFI protocol notes
- `phases/`: phase plans (Read ID, Page Write, Error Injection)
